# Wordstat: исправленная методика измерения интереса к профессиям

**Версия 2 — 26.10.2026.** Причина изменения: фразы «как стать [профессией]» слишком узкие, чтобы представлять интерес к профессии целиком.

## 1. Три независимых измерения

Для каждой из 7 новых профессий собираем:

| Слой | Пример | Как интерпретировать |
|---|---|---|
| **Широкая популярность названия** (основной) | `системный аналитик` | Сколько поисков содержит термин (включая вакансии, зарплаты, обязанности и другие намерения) |
| **Интерес к освоению** | `обучение системный аналитик` | Интерес к изучению направления, но не обязательно интерес к ПРОБЕ |
| **Карьерный вход** | `стажировка системный аналитик` | Интерес к поиску стартовой работы, не число стажировок |

Основной список: **[21 запрос по 7 профессиям](../data/interest_wordstat_v2_template.csv)**. Старый список из 14 фраз `как стать` / `стажировка` сохраняется в репозитории для истории, но **больше не считается основой итогового сравнения**.

**Не складывать** частоты из трёх типов запросов: они вложены и пересекаются. Каждому измерению соответствует отдельная колонка для сравнения и отдельная интерпретация.

## 2. Единые параметры в Wordstat

- Вкладка **«Динамика»**, детализация **«По месяцам»**.
- Срок: **октябрь 2025 — сентябрь 2026**, 12 полных месяцев.
- География: **Россия**, не «Все регионы» (отдельная выборка, которую нельзя смешивать).
- Устройства: все включены, одинаково для всех запросов.
- Копировать **все 12 помесячных значений**, желательно через кнопку «Скачать», а не по графику.
- Фиксировать буквальный введённый запрос и любые поисковые операторы; использовать одинаковые параметры для всех 7 ролей.

**Не обязательно сначала собирать 21 выгрузку.** Чтобы получить основной рейтинг общей популярности, сначала соберите **7 широких названий без добавления «как стать»**, затем отдельно 7 поисков по обучению и 7 по стажировкам.

Официальная документация: [операторы Wordstat](https://yandex.ru/support2/wordstat/ru/content/operators) и [общее руководство](https://yandex.ru/support2/wordstat/ru/).

## 3. Широкая фраза — это верхняя оценка интереса к теме, а не пользователей ПРОБЫ

Запрос `системный аналитик` может включать «зарплата», «обязанности», «вакансии», «резюме», «курс», «чем занимается». Это полезно для общего масштаба внимания. Но **поиск не равен числу уникальных людей**, а пользователи могут быть действующими аналитиками, рекрутерами и т. п.

Чтобы оценить именно намерение и подготовиться к продуктовым решениям:
1. Изучить **«Топы запросов»** у широко сформулированной профессии.
2. Разделить уточняющие запросы на: изучение/вход/работа/зарплата/прочее.
3. Вывести отдельные показатели обучения и стажировок для семи направлений.
4. Дальше проверить прямой интерес к пробе на самом продукте: показы карточек → клики «хочу попробовать» (план [здесь](proba-interest-experiment.md)).

Операторы `" "` и `!` позволяют уточнить состав фразы и форму слов соответственно. **Широкую частоту и статистику запроса в кавычках нельзя считать одной метрикой.** В отчёте всегда подписывать режим.

## 4. Дополнительные названия и семантические ловушки

- **Продакт-менеджер** и **продуктовый аналитик** — разные профессии.
- `продакт`, `продакт менеджер` и `продуктовый менеджер` — разные формулировки, их значения могут пересекаться. Суммировать их механически нельзя.
- Для frontend дополнительно можно проверить `frontend разработчик` и `фронтенд разработчик` как варианты одного направления, **но отдельно**; аналогично Python / питон и Data Scientist / дата сайентист.
- Запрос `менеджер проектов` может включать управление строительными и не-IT проектами — это широкий спрос по роли, не конкретно спрос на IT-пробу.

## 5. Что уже принесено пользователем

Скриншоты от 26.10.2026 (табличная часть, где она видна): **4 отдельных фразы «как стать...»**, по **11 месяцам октябрь 2025 — август 2026**. На скриншотах выбран пункт **«Все регионы»** и все устройства, хотя для нового сопоставимого исследования выбрана Россия.

По 4 фразам вручную занесены **44 видимых помесячных значения** в [исторический CSV](../data/wordstat_how_to_partial_2026-10-26.csv). Четыре значения сентября не видны в таблицах на снимках и оставлены **пустыми**, а не придуманы. Скриншоты не публикуются в открытом репозитории.

Важная детализация: 3 фразы относятся к **продуктовому аналитику / продакт-менеджеру**, которые **не входят** в 7 кандидатов нового каталога; 1 фраза относится к системному аналитику. Это не 4 независимых измерения спроса на одного «продакта».

Поэтому **не включать исторические 44 точки** в итоговую модель для России без отдельной пометки и не интерполировать сентябрь по графику.

## 6. Проверка полноты

```bash
python scripts/validate_interest_input.py
```

Проверка учитывает старый и новый шаблоны и 44 видимых значения. **Рейтинг не рассчитывается**, пока не появятся сопоставимые данные по семи названиям для России.

**Уверенность в необходимости сменить методику — высокая**; доверие к фактической сравнительной популярности семи ролей по этим четырём скриншотам — низкое.
