# Данные: происхождение и ограничения

Этот набор — **исторический поисковый срез от 17.10.2026**, ранее сохранённый при предварительном анализе открытых страниц hh.ru, а **не** официальный API-экспорт, статистическая выборка всех вакансий или подтверждённые данные Wordstat. При открытии ссылок сегодня значения и порядок объявлений могут измениться. Точные значения на историческую дату независимо не архивировались.

## Исходные файлы
- `hh_search_snapshot_2026-10-17.csv` — 12 записанных значений числа **поисковых совпадений** на страницах hh.ru в контексте Москвы, без унифицированного фильтра «по точному названию».
- `listing_quality_audit_2026-10-17.csv` — ручная классификация **первых двух** видимых объявлений по каждой странице на «Да», «Смежная», «Нет» (n=24).
- `search_ranked_2026-10-17.csv` и `relevance_summary_2026-10-17.csv` — вычисляемые агрегаты, создаваемые скриптом.

**Нельзя:** считать совпадения количеством уникальных рабочих мест; складывать значения 12 пересекающихся поисков; выводить проценты релевантности рынка из неслучайного n=24; оценивать студенческий интерес или частоту навыков по этим файлам.

**Ограничение проверяемости:** источник содержит ссылку на динамическую поисковую страницу, но не стабильный ID объявления, экспорт результатов и снимок HTML. Следовательно, любой конкретный исторический заголовок нельзя независимо воспроизвести с высокой уверенностью. Это открытое ограничение кейса, а не скрытый недостаток.

## Воспроизведение
Из корня репозитория:

```bash
python -m pip install -r requirements.txt
python scripts/analyze_snapshot.py
```

Скрипт проверит схему, размер среза и основные ограничения, затем пересчитает агрегаты и обновит два SVG-графика. Используемые библиотеки: Python и Pandas; визуализации создаются как текстовые SVG без дополнительных зависимостей.
